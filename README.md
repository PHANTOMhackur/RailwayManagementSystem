# Railway Management System 🚆

A C++ console-based Railway Management System developed using Object-Oriented Programming.

## Features

- Add New Train Record
- Display All Train Records
- Search Train by Train Number
- Exit System

## Technologies Used

- C++
- Object-Oriented Programming
- Classes and Objects
- Constructors and Destructors
- Static Data Members
- Encapsulation
- Arrays
- Functions

## How to Run

Compile the program:

g++ RailwaySystem.cpp -o RailwaySystem.exe

Run:

./RailwaySystem.exe
